# Project Submissions

Upload your project notebook here. It is evaluated automatically against the milestone rubric, **once per submission**, usually within 15 minutes.

## Where to upload

| Milestone | Folder |
|---|---|
| Milestone 1 | `Submission-Milestone1/` |
| Milestone 2 | `Submission-Milestone2/` |
| Milestone 3 | `Submission-Milestone3/` |
| Milestone 4 | `Submission-Milestone4/` |

## File name

`<Your_Name>_<project>.ipynb`, using one of these project keywords:

| Project | Keyword |
|---|---|
| Loan Default Prediction | `loan_default` |
| Retail Customer Purchase Behaviour | `retail_purchase` |
| Liver Disease Prediction | `healthcare` |

Example: `Submission-Milestone1/Priya_Venkatesh_loan_default.ipynb`

Use the **same name** for every milestone so your scores line up on the dashboard.

## How to upload

1. Click **Add file → Upload files**.
2. Drag in your notebook.
3. In the path box at the top, type the folder name followed by `/`, e.g. `Submission-Milestone1/`.
4. Click **Commit changes**.

## Your score

- A comment with your score and a link to your dashboard appears on your upload commit (open it from the repo's **commits** list).
- **My results page:** open the dashboard link from your instructor, choose your name, and bookmark it.
- Detailed feedback files: `evaluation-results/feedback/`

Your first upload for a milestone is the one that is scored. Check your notebook before uploading.
